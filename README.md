# Java Servlet Learning Project

This is a small project I made while learning **Java Servlets and server-side web development**.

The main goal of this project was to understand how a Java program can work with a web browser and handle requests and responses.

### What I learned

* Basic Java Servlet concepts
* How HTTP requests and responses work
* Using `HttpServlet`
* Handling `GET` and `POST` requests
* Creating dynamic HTML using Java
* Basic server-side web development
* Connecting Java with MySQL using JDBC
* How a web application runs on a servlet container

### Tech Used

* Java
* Java Servlet
* HTML
* MySQL
* JDBC
* Apache Tomcat
* NetBeans

This was mainly a **learning project**, and it helped me understand the basics of how Java works on the server side.
